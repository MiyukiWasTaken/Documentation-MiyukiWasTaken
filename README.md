# Documentation de machines au sein du MakerSpace d’UniLaSalle Amiens

Bienvenue sur le site de documentation de mes travaux au sein du MakerSpace d’UniLaSalle Amiens. Vous trouverez dans ce projet un site dans lequel figure une documentation de plusieurs machines du MakerSpace, leur fonctionnement, les gestes de sécurité à adopter, ainsi qu’une documentation continue de ce stage pour mettre en lumière les avancées, les projets, les erreurs et leurs solutions.
